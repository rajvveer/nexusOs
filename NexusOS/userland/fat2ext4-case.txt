# True case of 8.3-compatible names in a user's home folder (userland/fat2ext4.py --case-list).
# NexusOS's FAT32 driver stores a name that fits 8.3 ("Default", "History", "CURRENT") as a bare short entry, so the
# case is lost; ext4 is case-sensitive and the applications open these names with their own spelling. Each line is a
# path; it is matched as a path suffix of at least parent/name (never by the bare name), so "Default/History" only
# names History inside a Default folder. A folder holding "Local State" (Chromium/Electron user data) gets Default,
# Crashpad, User, Cache, GPUCache, Backups, Network, Cookies; LevelDB folders (a MANIFEST-*) get LOCK, CURRENT, LOG,
# LOG.old (fat2ext4.py).
